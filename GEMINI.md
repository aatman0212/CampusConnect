# Antigravity Workspace Guidelines & Autonomous Execution Rules

## Autonomous Execution & Non-Interactive Policy
1. **Auto-Proceed on All Tasks**:
   - Always proceed directly with implementation, file edits, testing, and terminal commands without stopping for manual confirmation or intermediate check-ins.
   - Do not trigger interactive planning modals or ask for approval on straightforward implementation steps.
2. **Proactive Command Execution**:
   - Proactively run build commands, local test servers, git commits, and verifications autonomously.
3. **No Unnecessary Prompting**:
   - Avoid asking trivial questions or asking permission to read URLs, view files, or run tests. Assume full approval to execute the user's intent.
